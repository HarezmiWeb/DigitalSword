🎮 Oyun Satış Sitesi

Kullanıcıların oyunları inceleyebildiği ve satın alabildiği, kullanıcı giriş sistemi ve yönetici paneli içeren web tabanlı bir oyun satış platformu.

📌 Proje Hakkında

Oyuncuların farklı oyunları keşfedebileceği, oyun kataloğunu inceleyebileceği ve favori oyunlarını satın alabileceği kullanıcı dostu bir platform oluşturmayı amaçlamaktadır.

Proje kapsamında kullanıcı giriş sistemi ve site yönetimi için bir yönetici paneli bulunmaktadır. Böylece çevrim içi oyun satış sitelerinin temel işlevleri tek bir platformda bir araya getirilmektedir.

✨ Özellikler

- **Oyun Kataloğu:** Kullanıcıların mevcut oyunları inceleyebilmesi.
- **Kullanıcı Girişi:** Kullanıcıların hesapları üzerinden sisteme giriş yapabilmesi.
- **Admin Paneli:** Web sitesinin yönetimi için özel yönetici arayüzü.
- **Çevrim İçi Oyun Satışı:** Oyunların web sitesi üzerinden satın alınabilmesini sağlayan yapı.
- **Kullanıcı Dostu Arayüz:** Kolay ve anlaşılır bir gezinme deneyimi.

🛠️ Kullanılan Teknolojiler

- C#
- ASP.NET Core MVC
- HTML5
- CSS3
- JavaScript
  
🎯 Projenin Amacı

- Web tabanlı bir oyun satış platformu geliştirmek.
- Kullanıcı giriş sistemini uygulamak.
- Web sitesi yönetimi için bir admin paneli oluşturmak.
- MVC mimarisi ve web geliştirme konusunda deneyim kazanmak.
- Düzenli ve sürdürülebilir bir web uygulaması geliştirmek.
  
📌 Proje Durumu

Bu proje, web geliştirme alanında uygulama deneyimi kazanmak amacıyla geliştirilmektedir. Temel olarak çevrim içi oyun satışı, kullanıcı girişi ve yönetici paneli özelliklerine odaklanmaktadır.
